# GRE Quant Daily

A daily 10–15 minute GRE quant trainer. One adaptive topic per day: quick reading → 4 questions in real GRE formats (Quantitative Comparison, multiple choice, select-all, numeric entry) → confidence rating. Tracks mastery per topic and a daily streak. All progress is stored on-device (localStorage).

## Put it on GitHub Pages (~3 minutes)

1. Go to https://github.com/new → name the repo `gre-quant-daily` → set it **Public** → Create repository.
2. On the new repo page, click **uploading an existing file**, drag in `index.html` (and this README if you want), and click **Commit changes**.
3. Go to the repo's **Settings → Pages** (left sidebar). Under "Build and deployment," set Source to **Deploy from a branch**, pick branch **main** and folder **/ (root)**, and Save.

After a minute or two your site is live at:

`https://<your-username>.github.io/gre-quant-daily/`

## On your phone

Open the URL in Safari/Chrome → Share → **Add to Home Screen**. It'll open full-screen like an app.

## Notes

- **Progress is per device.** Use Export/Import (bottom of the Topics menu) to copy progress between phone and laptop.
- **Streak** counts days with at least one completed session. Bonus rounds don't add extra streak.
- **Mastery** = 55% your accuracy on that topic (all attempts) + 45% your latest confidence rating.
- **Adaptive picking**: unseen topics first (in syllabus order), then your weakest topic.
- Tap the calendar pill on the home screen to change your test date (default 2026-07-24).
- To update content later, just edit `index.html` in the repo and commit — Pages redeploys automatically.
